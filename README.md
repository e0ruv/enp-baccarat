# ENP BACCARAT — 가상 머니 모의 바카라

실제 화폐를 사용하지 않는 **가상 머니 전용** 바카라 시뮬레이터입니다.
Evolution 바카라 테이블 스타일 — 블랙 펠트 · 골드 세리프 · PLAYER(좌)/BANKER(우) 수평 배치 ·
5존 커브 베팅 매트 · 골드 프레임 보너스 슬롯 5칸 — 에 3개의 테마 테이블(스피드 / 벚꽃 / 눈꽃)을 얹었습니다.

## 실행

정적 사이트입니다. 폴더를 그대로 열거나 로컬 서버로 띄우면 됩니다.

```bash
cd baccarat-sim
python3 -m http.server 8000
# http://localhost:8000
```

## 테이블

| 테이블 | 영문 | 특징 | 배당 |
|---|---|---|---|
| 🚀 스피드 | SPEED | 0.35초 즉시 딜, 보너스 카드 없음 | P 1:1 · B 0.95:1 · T 8:1 · 페어 11:1 |
| 🌸 벚꽃 | BLOSSOM | 벚꽃 카드 1~5장 (2x·3x·4x·5x·8x 중첩) | 동일 + 보너스 배수 |
| ❄️ 눈꽃 | SNOWFLAKE | 눈꽃 크리스탈 1~5장 (2x·3x·4x·5x·8x 중첩) | 동일 + 보너스 배수 |

- 기본 테이블: **벚꽃(BLOSSOM)**
- 보너스 카드는 승리한 핸드(또는 페어)에 포함되면 배당이 곱연산으로 중첩됩니다. (최대 512x)
- 8덱 416장 · 피셔-예이츠 셔플 · 14장 이하 자동 셔플 · 수동 셔플
- 정식 푼토 방코 서드카드 룰 (내추럴 8·9, 플레이어 0–5, 뱅커 태블로)

## 화면 구성 (라이브 테이블 스튜디오)

- **풀 뷰포트 3D 테이블**: 아트데코 스튜디오(골드 기둥·벨벳 커튼·볼류메트릭 스포트라이트) 위에
  `perspective` 3D로 기울어진 펠트 테이블 하나. 테이블 아래 별도 박스 패널 없이 모두 테이블 위에 얹힘.
- **가상 딜러**: 상단 중앙 마호가니 레일 뒤에 붓그림풍 딜러(크림슨 셔츠 + 블랙 베스트 + 골드 트림 + 화이트 글러브).
  카드가 나갈 때마다 팔이 슈 쪽으로 뻗고, 3D 카드가 슈에서 해당 스팟으로 날아가 뒤집힙니다. 대기 중엔 호흡/눈깜빡임.
- **PLAYER / BANKER**: 좌·우 세리프 타이틀 + 골드 링 스코어. 카드 아래 매칭된 보너스 카드에는 `8x`·`5x` 금빛 배지.
- **베팅 매트**: P페어 · PLAYER · TIE(아치) · BANKER · B페어 5존 컴팩트 필-아치. 베팅 시 3D 칩 스택.
- **보너스 슬롯**: 하단 좌측 5개의 세로 골드 프레임 슬롯(상단 배수 필 + 카드).
- **하단 바**: 3D 라운드 칩 · 금액 · 총 베팅/차감 · 재베팅/되돌리기/초기화 · `DEAL` · 미니 출목표.
- 모바일(390×844)은 같은 흐름(테이블 → 매트 → 보너스 슬롯 → 칩/딜)을 세로로 유지하고 출목표는 드로어.

## 기능

- 베팅: 플레이어 / 뱅커 / 타이 / P페어 / B페어, 칩 1천~50만, ½·2×, 되돌리기·초기화·재베팅
- 베팅 매트: 진화 스타일 5존 커브 아치(P페어 · PLAYER · TIE · BANKER · B페어), 존을 누르면 금빛 칩 스택이 금액과 함께 올라갑니다
- 쪼기(Squeeze) 모드: 카드를 탭해서 한 장씩 오픈, 전체 오픈 버튼
- 라이브 배수: 카드가 공개될 때마다 매칭된 보너스 카드 위에 금빛 `4x` 배지가 뜨고 카드 테두리가 점등, `⚡ 플레이어 ×40` 칩도 실시간 표시
- 빅윈 연출: 배수 승리 시 골드/테마 연출 + `+₩` 배너
- 출목표: 원판(비드 플레이트) · 빅로드(타이 슬래시·페어 도트) · 최근 기록 · 통계
  (데스크톱은 우측 컴팩트 패널, 모바일은 `출목표` 버튼으로 여는 바텀 드로어)
- Web Audio 합성 사운드 (칩·카드·당첨·테마음), 음소거 지원
- 계정: 아이디 + PIN 회원가입/로그인, 게스트 즉시 플레이, 계정별 잔액·기록 저장(localStorage)
- 히든 관리자: 로고 더블클릭/더블탭 → PIN `6160` → 회원 목록, 잔액 +/−·초기화, GitHub 동기화(선택)

## 참고

- 모든 금액은 가상 머니입니다. 충전은 무료이며 실제 결제가 발생하지 않습니다.
- 계정·잔액·기록은 브라우저 localStorage에만 저장됩니다. (서버 없음)
- GitHub 동기화는 관리자에서 리포지토리(`owner/repo`)와 PAT를 입력해 사용합니다.
  PAT는 이 기기의 localStorage에만 저장되며, `baccarat/users.json` 경로로 올리고/불러옵니다.
