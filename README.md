# ENP BACCARAT — 가상 머니 모의 바카라

실제 화폐를 사용하지 않는 **가상 머니 전용** 바카라 시뮬레이터입니다.
실제 라이브 바카라(Stake · Evolution `Korean Speed Baccarat`)의 모바일 세로 화면 구성을 기준으로
**딜러 스튜디오 · 출목표 · 베팅 매트** 3단을 한 화면에 담았습니다.

## 실행

정적 사이트입니다. 폴더를 그대로 열거나 로컬 서버로 띄우면 됩니다.

```bash
cd baccarat-sim
python3 -m http.server 8000
# http://localhost:8000
```

## 화면 구성

### 1단 · 딜러 스튜디오
- 가상 일러스트 딜러 + 테이블(`PLAYER` | `BANKER`, 우측 슈).
- 베팅 중: 우측 상단 원형 **카운트다운**(20초 주기, 표시용 · 자동 딜 없음), 좌·우 하단 `0` | `0` 점수 배지.
- 카드가 나오면 테이블로 줌 포커스되며 카드가 놓이고, 승리한 쪽 점수 배지가 금빛으로 강조,
  중앙에 `P` / `B` / `T` 결과 배지가 뜹니다.
- 벚꽃·눈꽃 테이블은 상단에 보너스 카드 레일(1~5장, ×2~×8)이 표시됩니다.

### 2단 · 출목표 (항상 보임 · 서랍 없음)
- **빅로드** + 하단 보조 로드 3종(**중국점 1·2·3군**) + 우측 **비드로드**(P/B/T 세로 이력).
- 통계 `#26 P 12 B 12 T 2`, 타이 확률 `0%`, 예측 표시줄 `P ○●●/` `B ●○○/`.
- 우측 하단 화살표로 보조 로드를 접어 빅로드를 넓게 볼 수 있습니다.

### 3단 · 베팅 매트
| 줄 | 칸 |
|---|---|
| 1 | `플레이어`(파랑) · `무 8:1`(초록 아치) · `뱅커`(빨강) — 딜링 중이면 칸 안에 **미니 카드**가 실시간 표시 |
| 2 | `플레이어 페어 11:1` · `플레이어 보너스 1~30:1` · `뱅커 보너스 1~30:1` · `뱅커 페어 11:1` |
| 3 | `퍼펙트 페어 (하나 25:1 · 더블 200:1)` · `이더 페어 5:1` |

그 아래 칩 선택(1천~50만) · 실행 취소 · 재베팅 · ½ · 2× · 지우기 · 딜, 최하단 상태바에
`총 베팅` · `잔고` · `테이블명 / 한도`가 표시됩니다.

## 테이블

| 테이블 | 영문 | 특징 |
|---|---|---|
| 🚀 스피드 | SPEED | 0.35초 즉시 딜, 보너스 카드 없음 |
| 🌸 벚꽃 | BLOSSOM | 벚꽃 카드 1~5장 (2x·3x·4x·5x·8x 중첩) |
| ❄️ 눈꽃 | SNOWFLAKE | 눈꽃 크리스탈 1~5장 (2x·3x·4x·5x·8x 중첩) |

- 기본 테이블: **벚꽃(BLOSSOM)**
- 보너스 카드는 승리한 베팅에 포함되면 배당이 곱연산으로 중첩됩니다. (최대 512x)
- 8덱 416장 · 피셔-예이츠 셔플 · 14장 이하 자동 셔플 · 수동 셔플(슈 클릭)
- 정식 푼토 방코 서드카드 룰 (내추럴 8·9, 플레이어 0–5, 뱅커 태블로)

## 배당 · 정산

| 베팅 | 조건 | 배당 |
|---|---|---|
| 플레이어 / 뱅커 | 해당 핸드 승리 | 1:1 · 0.95:1 (노 커미션 시 뱅커 6 = 0.5:1) |
| 무 (타이) | 양쪽 합계 동일 | 8:1 · 플레이어·뱅커 베팅은 푸시 |
| 플레이어 · 뱅커 페어 | 첫 두 장 같은 랭크 | 11:1 |
| 플레이어 · 뱅커 보너스 | 해당 핸드 합계 4~9 | 4→2:1 · 5→3:1 · 6→4:1 · 7→6:1 · 8→10:1 · 9→30:1 |
| 퍼펙트 페어 | 첫 두 장 같은 랭크 + 같은 무늬(하나) / 양쪽 모두(더블) | 25:1 · 200:1 |
| 이더 페어 | 어느 한쪽이든 페어 | 5:1 |

벚꽃·눈꽃 테이블에서는 위 사이드 베팅에도 보너스 카드 배수가 곱해집니다.
정산은 모두 `js/engine.js`의 `settleRound()`가 담당하고, UI는 그 결과만 표시합니다.

## 기능

- **베팅 금액 이동**: 칩이 놓인 칸을 **길게 누르거나(0.38초) 끌어서** 다른 칸에 놓으면 금액이 그대로 옮겨집니다.
  (모바일 터치 · 데스크톱 마우스 모두) 잔액 변화 없이 이동만 기록되며 `↺` 실행 취소로 되돌릴 수 있습니다.
- **더블탭 확대 방지**: `viewport`에 `maximum-scale=1, user-scalable=no`, 인터랙티브 요소 전부에
  `touch-action: manipulation`(베팅 매트는 `none`), 핀치·더블탭 기본동작 차단. 상단 로고 더블탭 `6160` 관리자는 그대로 동작합니다.
- 칩 1천~50만, ½·2×, 되돌리기 · 초기화 · 재베팅, 스피드 자동 재베팅
- 쪼기(Squeeze) 모드: 카드를 탭해서 한 장씩 오픈, 전체 오픈 버튼
- 라이브 배수: 카드가 공개될 때마다 매칭된 보너스 카드 위에 금빛 `4x` 배지·카드 테두리 점등, `⚡ 플레이어 ×40` 칩 표시
- 빅윈 연출: 배수 승리 시 골드 연출 + `+₩` 배너
- 출목표: 빅로드 · 중국점 1·2·3군 · 비드로드 · 통계 · 최근 기록(데스크톱)
- Web Audio 합성 사운드 (칩·카드·당첨·테마음), 음소거 지원
- 계정: 아이디 + PIN 회원가입/로그인, 게스트 즉시 플레이, 계정별 잔액·기록 저장(localStorage)
- 히든 관리자: 로고 더블클릭/더블탭 → PIN `6160` → 회원 목록, 잔액 +/−·초기화, GitHub 동기화(선택)
- 반응형: 모바일 세로(390×844) 3단 단일 화면 / 데스크톱(1440×900) 좌우 2단

## 참고

- 모든 금액은 가상 머니입니다. 충전은 무료이며 실제 결제가 발생하지 않습니다.
- 계정·잔액·기록은 브라우저 localStorage에만 저장됩니다. (서버 없음)
- GitHub 동기화는 관리자에서 리포지토리(`owner/repo`)와 PAT를 입력해 사용합니다.
  PAT는 이 기기의 localStorage에만 저장되며, `baccarat/users.json` 경로로 올리고/불러옵니다.
