# 그림장 분석기 · Baccarat Road Analyzer

다른 바카라 사이트를 플레이하면서 옆에 켜 두고 쓰는 **독립형 그림장 분석 웹앱**입니다.
결과를 한 판씩 눌러 찍으면 빅로드·중국점 1·2·3군·비드로드가 즉시 그려지고, 그 위에서 다음 판 패턴을 참고용으로 분석합니다.

```
baccarat-analyzer/
├── index.html
├── css/style.css
├── js/
│   ├── engine.js     ← baccarat-sim/js/engine.js 그대로 (빅로드 · 중국점 1·2·3군 규칙)
│   ├── analyzer.js   ← 패턴 감지 · 1·2·3군 일치도 · 종합 추천 (UI 없음)
│   └── app.js        ← 입력 · 렌더 · 세션 저장
└── tests/
    ├── verify.py     ← Playwright 검증 + 미리보기 캡처 (31개 체크)
    └── smoke.py      ← 빠른 로드/스크린샷 확인
```

## 쓰는 법

1. 폴더를 그대로 웹 서버에 올리거나 GitHub Pages 로 배포합니다(빌드 없음, 파일만).
2. 사파리에서 열고 **홈 화면에 추가**하면 주소창 없이 전체 화면 앱처럼 뜹니다
   (`apple-mobile-web-app-capable`, `viewport-fit=cover` + safe-area 대응).
3. 아래쪽 큰 **P · B · T** 버튼으로 결과를 한 판씩 입력합니다.
   - `되돌리기` — 마지막 한 판 취소
   - `새 슈` — 현재 슈를 세션 기록에 저장하고 새 슈 시작 (기록 시트에서 다시 불러오기 가능)
   - 오른쪽 위 **시계 아이콘** — 세션 기록(지난 슈 목록)
4. 데스크톱에서는 `P` `B` `T` 키, `Ctrl/⌘+Z`(되돌리기), `Esc`(시트 닫기)도 됩니다.

## 화면

- **그림장** — 흰 격자 보드
  - 빅로드 6행 (타이는 초록 대각선 슬래시, 6행을 넘는 연속은 오른쪽 용꼬리)
  - 중국점 1군(대로우보이) · 2군(스몰로드) · 3군(칵로치)
  - 비드로드 6행 (P 파랑 · B 빨강 · T 초록)
  - 최신 열이 항상 오른쪽 끝에 보이도록 자동으로 밀립니다.
- **추천 픽** — `PLAYER 우세` / `BANKER 우세` / `관망(혼조)` 배지 + 신뢰도 %, P/B 게이지, 근거 4줄
- **1·2·3군 일치도** — 다음 판을 P로 가정했을 때와 B로 가정했을 때 1·2·3군에 찍힐 색(빨강/파랑)을 미리 보여주고,
  세 군이 같은 색으로 몰리는 쪽을 금색으로 강조합니다. `P 가정` / `B 가정` / `P 미리보기` / `B 미리보기` 를 누르면
  그림장에 다음 칸이 **깜빡이는 미리보기**로 표시됩니다(6초 뒤 자동 해제).
- **패턴 감지** — 장줄(연승), 퐁당(1-1 교차), 투투(2-2 교차), 원투(1-2 교차), 최근 10판·20판 승률, 현재/최장 장줄
- **슈 요약** — 데스크톱에서만 표시 (판수, P:B 비율, 타이, 평균 장줄, 교차 패턴 발생 횟수)

> 추천 픽은 **참고용 패턴 분석**입니다. 바카라는 매 판이 독립적인 게임이고 어떤 분석도 승리를 보장하지 않습니다.
> 그래서 화면 하단에 항상 그 문구를 작게 띄우고, 신뢰도는 근거가 적으면 자동으로 낮아지도록 만들었습니다(최대 82%).

## 판단 기준 (analyzer.js)

| 근거 | 방향 | 가중치 |
|---|---|---|
| 1·2·3군 올빨강(흐름 유지) / 올파랑(꺾임) | 그 가정 쪽 | 0.62 / 0.52 (2군만 일치 0.26) |
| 장줄 (3연 이상) | 연승 지속 쪽 | 0.20 ~ 0.62 (길수록↑) |
| 퐁당 / 투투 / 원투 | 교차 다음 칸 | 0.45 / 0.40 / 0.35 |
| 최근 10판 편향 | 다수 쪽 | 0.18 × 격차 |
| 슈 전체 편향 (20판 이상) | 다수 쪽 | 0.12 × 격차 |

방향이 갈리면 `관망(혼조)`로 떨어지고, 근거 총량이 적으면(`evidence`) 신뢰도가 낮게 나옵니다.
P·B 양쪽이 동시에 "일치"하면 거울상(유지/꺾임)일 뿐이라 일치 근거에서 제외합니다.

## 검증

```bash
LD_LIBRARY_PATH=/workspace/.libs/usr/lib/x86_64-linux-gnu python3 tests/verify.py
```

- 빅로드 6행 · 용꼬리 · 타이 처리
- 중국점 1·2·3군: 손계산 케이스 + 독립 파이썬 구현과 무작위 200슈 대조
- P/B/T 입력, 되돌리기, 새 슈 → 세션 기록, 새로고침 후 localStorage 복원
- 다음 판 미리보기 칸 = 실제 입력 시 칸
- 오버플로 0 · 콘솔 에러 0: 393×852(iPhone 16 Pro), 375×667(SE), 430×932(Pro Max), 852×393(가로), 1440×900(데스크톱)
- 300판 연속 입력 스트레스: 콘솔 에러 0 · 오버플로 0 (그림장은 최신 열 기준으로 자동 이동)
- 1탭 처리 시간(입력→렌더) 평균 **0.5ms** — 칸 노드를 재사용하고 렌더 중 레이아웃을 읽지 않도록 구성

## 메모

- `js/engine.js` 는 `baccarat-sim/js/engine.js` 사본입니다. 그림장 규칙을 한쪽에서 고치면 다른 쪽도 같이 복사해야 합니다.
- 데이터는 기기 브라우저의 `localStorage`(`enp.baccarat-analyzer.v1`)에만 저장됩니다. 서버 전송 없음.
- 최근 40개 슈까지 기록을 보관합니다.
